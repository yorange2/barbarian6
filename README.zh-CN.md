# 🪓 Barbarian 6（蛮族 6）

[English](README.md) · **简体中文**

一款运行在浏览器中的简化版《文明》风格六边形策略游戏。在你的战团被消灭之前，摧毁所有蛮族营地、消灭蛮族，并击败敌对文明。

**在线试玩**：https://yorange2.github.io/barbarian6/ （通过 GitHub Actions 从 `main` 分支自动部署）

## 运行

```sh
npm install
npm run dev      # 带热更新的开发服务器
npm run build    # 生产构建，输出到 dist/（可部署到 GitHub Pages / itch.io）
```

## 玩法

- **点击**你的单位（蓝色）以选中；高亮的格子是它本回合可移动的范围。
- **点击**带红圈的相邻敌人发起攻击（防御方会反击）。
- **拖动**平移地图，**滚轮**缩放，**回车键**（或按钮）结束回合。
- 文明式地块：地形（草原 2🌾、平原 1🌾1⚙、沙漠、冻土 1🌾）可带一个丘陵属性
  （+1⚙、+1 移动消耗、+3 防御），并在其上叠加至多一种地貌——森林（+1⚙、+3 防御、
  可砍伐获得 20⚙）、雨林（+1🌾、+3 防御、可砍伐）、沼泽（+1🌾、−2 防御、可排干）、
  绿洲（+3🌾，仅限沙漠）。水域和山脉无法通行。防御方享受所在地块的战斗加成。城市产出
  为其领土内所有地块产出之和；每点人口消耗 2 食物。
- 营地 ⛺ 每 6 回合刷出一个新蛮族——移动到营地上即可将其摧毁。
- 开拓者 🚩 建立城市（需与其他城市相距 3 格以上）。城市每回合积累生产力 ⚙ 并生产新单位——
  点击城市选择生产项目。蛮族会攻击城市；城市血量归零即被夷平（敌对文明可占领城市）。
- 城市成长：食物 🌾 每回合积累并提升人口，人口带来生产力和科研。农场供养人口增长；
  矿场和伐木场增加生产力。
- 城市拥有领土（彩色边界）：建城时 1 格，人口达到 3 时扩展到 2 格，人口 5 时扩展到 3 格。
  已归属的格子不会易主；城市被夷平后其领土释放。
- 建造者 🔨 有 3 次建造次数，可修建农场 🌾（草原）、矿场 ⛏️（丘陵，需采矿科技）
  或伐木场 🪵（森林）——只能在己方领土内建造，且只有城市领土内的改良设施才计入其产出。
- 科技研究 🧪：从顶栏的科技按钮选择科技。采矿 → 青铜器（🛡️ 长矛兵）、轮子（🏇 骑手）、
  砖石建筑（城墙）；箭术解锁 🏹 弓箭手，可隔 2 格攻击且不受反击。
- 整回合休整不动的单位回复 4 点生命。

## 多语言

支持 English 和简体中文，可从顶栏切换（保存在 `localStorage`，默认跟随浏览器语言）。
所有界面文本集中在 `src/i18n.ts`；战斗日志存储的是消息键而非文本，因此切换语言时历史日志
也会被重新翻译。要新增一种语言，在 `src/i18n.ts` 中添加一份词典，并在 `index.html`
的语言选择器里加一个 `<option>`。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `src/hex.ts` | 轴向六边形坐标数学（参见 [Red Blob Games](https://www.redblobgames.com/grids/hexagons/)） |
| `src/map.ts` | 地形类型与随机地图生成 |
| `src/game.ts` | 游戏规则：单位、移动、战斗、蛮族 AI、胜负判定 |
| `src/render.ts` | 地图、单位与高亮的 Canvas 2D 渲染 |
| `src/main.ts` | 输入处理、镜头，以及 DOM 界面的连接 |
